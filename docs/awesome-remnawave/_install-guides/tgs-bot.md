### 📦 Key Features

- Telegram Bot + Mini App for selling VPN subscriptions
- Full integration with Remnawave
- Tariffs, trial subscriptions and promocodes
- YooKassa and CryptoBot payments
- Device management
- Referral system
- Support tickets
- Built-in admin panel
- Broadcasts and user management

### 🚀 Installation

```bash
git clone https://github.com/bruhxax/TGS-bot.git /opt/tgs-bot
cd /opt/tgs-bot
chmod +x install.sh
./install.sh
```

The installer will ask for:

- Telegram Bot Token
- Mini App domain
- Admin Telegram ID
- Remnawave Panel URL
- Remnawave API Token

After installation, open the bot and configure tariffs, payments and other settings through the built-in admin panel.
