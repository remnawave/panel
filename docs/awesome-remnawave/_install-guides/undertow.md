### Features

- **5 skills** for Remnawave 3.x, networking fundamentals, Cloudflare, censorship-resistant topologies and detection-signal audit
- **58 references** built only from official sources: docs.rw, github.com/remnawave, Cloudflare docs, RFCs
- **detection-auditor agent** for an independent audit of a setup before the final decision
- **English and Russian** plugins with the same content: `undertow-en` and `undertow-ru`

### Installation

Claude Code:

```text
/plugin marketplace add essilyasemenov/undertow
/plugin install undertow-en@undertow
```

Codex:

```bash
codex plugin marketplace add essilyasemenov/undertow
codex plugin add undertow-en@undertow
```

For the Russian version, install `undertow-ru@undertow` instead.
