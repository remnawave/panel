### Features

- **Universal Client Support** – Supports XRAY_JSON, MIHOMO, STASH, SINGBOX, CLASH, and XRAY_BASE64 response types
- **Browser Passthrough** – Pass through the Remnawave subscription page and its assets directly to the browser
- **Metadata Preservation** – Preserve primary subscription metadata and configuration sections unrelated to proxies
- **Fail-Open Behavior** – Fall back to the original primary configuration when merging fails
- **Alternative Subscription Pages** – Support subscription pages that return the same set of HTTP headers as the original Remnawave page
