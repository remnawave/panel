* 📦 **Plans** – Any number of plans, each with its own terms, prices, traffic and device limits. Availability for everyone, new or existing customers, a user list or a private link; export and import as a file. Switching plans keeps the paid remainder.
* 💳 **Payments** – Telegram Stars, YooKassa with auto-renewal, crypto, card transfer and more, each turned on separately. Lost payment notifications are re-checked automatically.

* 🎁 **Trial & Renewals** – Trial with optional purchase during it, expiry reminders, binding to existing panel users, device list with one-tap reset.

* 🛠 **Admin in Chat** – Sales, marketing, users (search, blocks, access modes, torrent blocker reports), panel connection, one-button updates, migration from remnashop.
* 🔐 **Security** – Settings encrypted in the database, the bot only touches panel users it manages, scam-registration guard, public / invite-only / whitelist access.
* 🚀 **Install in 4 steps** – Download `docker-compose.yml`, set the bot token and your Telegram ID, `docker compose up -d`, send `/start` — the setup wizard does the rest.
