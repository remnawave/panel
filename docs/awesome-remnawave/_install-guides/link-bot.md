### Key Features

- Telegram bot, Mini App, and browser dashboard for selling and managing Remnawave subscriptions
- Configurable tariffs, trials, traffic limits, device limits, and internal or external squad assignment
- YooKassa, CryptoPay, Telegram Stars, Lava, WATA, Platega, FreeKassa, and Heleket integrations
- Promocodes, referrals, reviews, support tickets, broadcasts, and subscription notifications
- Built-in administration panel for integrations, content, appearance, diagnostics, and feature management
- Maintenance mode, payment alerts, and configurable functionality
- Docker Compose deployment with PostgreSQL and automatic HTTPS

Detailed installation and configuration instructions are available in the [project repository](https://github.com/bruhxax/Link-Bot).
