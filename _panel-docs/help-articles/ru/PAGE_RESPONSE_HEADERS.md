## Хэдеры

Хэдеры – это заголовки, которые отправляются вместе с подпиской (ответом).

В Remnawave вы можете использовать ключ `rwEncodeBase64:` для того, чтобы закодировать значение хедера в base64.

Ниже приведен список популярных хедеров. Некоторые из них настроены по умолчанию.

### profile-title

Хэдер, который в основном используется для отображения названия профиля в клиентском приложении.

Ключ: `profile-title`

Пример значения: `rwEncodeBase64:Моя крутая подписка`

Значение по умолчанию: `rwEncodeBase64:Remnawave`

### profile-web-page-url

Используется для отображения ссылки на веб-страницу профиля в клиентском приложении.

Ключ: `profile-web-page-url`

Пример значения: `rwEncodeBase64:https://dummy.docs.rw`

Значение по умолчанию: `rwEncodeBase64:{{SUBSCRIPTION_URL}}`

### profile-update-interval

Используется для установки интервала обновления подписки в клиентском приложении.

Ключ: `profile-update-interval`

Пример значения: `1`

Значение по умолчанию: `12`

### support-url

Используется для установки ссылки на поддержку в клиентском приложении.

Ключ: `support-url`

Пример значения: `https://dummy.docs.rw`

Значение по умолчанию: `https://dummy.docs.rw`

## Переменные в значениях хэдеров

В значении любого хэдера можно использовать шаблонные переменные — например `{{USERNAME}}` или `{{SUBSCRIPTION_URL}}`. Перед отправкой ответа они заменяются на данные пользователя.

### Переменная `{{STATUS}}`

Подставляет статус подписки пользователя.

| Статус     | Значение по умолчанию |
| ---------- | --------------------- |
| `ACTIVE`   | `Active`              |
| `EXPIRED`  | `Expired`             |
| `LIMITED`  | `Limited`             |
| `DISABLED` | `Disabled`            |

Пример значения: `rwEncodeBase64:Ваша подписка: {{STATUS}}`

### Переменная `{{RESET_STRATEGY}}`

Подставляет стратегию сброса трафика. По умолчанию выводится само значение: `NO_RESET`, `DAY`, `WEEK`, `MONTH` или `MONTH_ROLLING`.

Пример значения: `rwEncodeBase64:Сброс: {{RESET_STRATEGY}}`

### Свои названия

Названия можно переопределить прямо в значении хэдера, перечислив пары `ЗНАЧЕНИЕ=название` через `|`. Переопределение поддерживают `{{STATUS}}` и `{{RESET_STRATEGY}}`.

Пример значения: `rwEncodeBase64:Ваша подписка {{STATUS:ACTIVE=✅ Активна|EXPIRED=😓 Истекла}}`

Результат для активного пользователя: `Ваша подписка ✅ Активна`

Пример значения: `rwEncodeBase64:Сброс: {{RESET_STRATEGY:NO_RESET=не сбрасывается|MONTH=раз в месяц}}`

Результат при месячном сбросе: `Сброс: раз в месяц`

Правила:

- Пары разделяются символом `|`.
- Значение от названия отделяет первый знак `=`, а имя переменной — первое двоеточие. Поэтому и `=`, и `:` внутри названия допустимы: `{{STATUS:ACTIVE=Статус: активна}}`.
- Пробелы внутри названия сохраняются как есть, включая ведущий.
- Перечислять все значения необязательно — незаданные останутся со значением по умолчанию.
- Неизвестное значение (например, опечатка `ACTIVEE=`) игнорируется, подставится значение по умолчанию.
- Внутри названия нельзя использовать `|`, `{` и `}`.

> ⚠️ Эмодзи, кириллица и любые другие не-ASCII символы допустимы только вместе с `rwEncodeBase64:`. HTTP-хэдеры не умеют передавать такие символы напрямую, и без кодирования подписка не будет отдана. Если `rwEncodeBase64:` не используется, ограничьтесь латиницей.
