## اسنیپت‌ها

اسنیپت یک قطعه‌ی نام‌گذاری‌شده از پیکربندی Xray است که یک بار ذخیره می‌شود و با نام خود در هر تعداد پروفایل جای‌گذاری می‌شود.

وقتی تعداد پروفایل‌ها زیاد می‌شود، هر تغییر کوچکی به کاری تکراری تبدیل می‌شود: فرض کنید ۱۰ پروفایل دارید و بخش مسیریابی در همه‌ی آن‌ها یکسان است. بدون اسنیپت باید همان ویرایش را ۱۰ بار تکرار کنید. با اسنیپت‌ها قانون را در یک جا تغییر می‌دهید و به‌طور خودکار در همه‌ی پروفایل‌هایی که به آن ارجاع می‌دهند اعمال می‌شود.

---

### قالب اسنیپت

اسنیپت **همیشه یک آرایه‌ی JSON از آبجکت‌ها** است، حتی اگر فقط یک آبجکت داخل آن باشد.

```json
[
  {
    "protocol": "freedom",
    "tag": "DIRECT"
  }
]
```

شرایط محتوا:

- باید یک آرایه باشد، نه یک آبجکت؛
- آرایه باید دست‌کم یک عضو داشته باشد؛
- آبجکت‌های خالی (`{}`) داخل آرایه مجاز نیستند.

---

### اسنیپت‌ها را کجا می‌توان جای‌گذاری کرد

اسنیپت در چهار جا جای‌گذاری می‌شود. در سه مورد از آن‌ها هدف یک آرایه است و ارجاع به شکل آبجکت `{ "snippet": "نام" }` نوشته می‌شود. در مورد چهارم هدف ریشه‌ی پیکربندی است و ارجاع به شکل آرایه‌ای از نام‌ها نوشته می‌شود.

#### outbounds\[\]

```json
{
  "outbounds": [
    {
      "snippet": "snippet-name"
    }
  ]
}
```

#### routing.rules\[\]

```json
{
  "routing": {
    "rules": [
      {
        "snippet": "snippet-name"
      }
    ]
  }
}
```

#### routing.balancers\[\]

```json
{
  "routing": {
    "balancers": [
      {
        "snippet": "snippet-name"
      }
    ]
  }
}
```

#### ریشه‌ی پیکربندی

در ریشه‌ی پیکربندی، ارجاع نه با یک آبجکت، بلکه با آرایه‌ای از نام‌ها در فیلد `snippets` تعریف می‌شود:

```json
{
  "snippets": ["log-preset", "dns-preset"],
  "inbounds": [],
  "outbounds": []
}
```

چنین اسنیپتی باید **بخش‌های سطح ریشه** را در خود داشته باشد. این همچنان یک آرایه از آبجکت‌ها است، فقط کلیدهای داخل آبجکت‌ها نام بخش‌های پیکربندی هستند:

```json
[
  {
    "log": {
      "loglevel": "debug"
    }
  }
]
```

بخش‌ها را هم می‌توان در عضوهای جداگانه‌ی آرایه پخش کرد و هم در یک آبجکت جمع کرد – نتیجه یکسان است:

```json
[
  {
    "log": {
      "loglevel": "debug"
    },
    "dns": {
      "servers": ["1.1.1.1"]
    }
  }
]
```

### جای‌گذاری چگونه انجام می‌شود

#### در آرایه‌ها

آبجکتِ دارای ارجاع به‌طور کامل با محتوای اسنیپت جایگزین می‌شود. اگر اسنیپت چند عضو داشته باشد – همه‌ی آن‌ها به جای همان یک ارجاع می‌نشینند.

پیش از جای‌گذاری:

```json
{
  "outbounds": [{ "snippet": "my-outbounds" }]
}
```

اسنیپت `my-outbounds`:

```json
[
  { "protocol": "freedom", "tag": "DIRECT" },
  { "protocol": "blackhole", "tag": "BLOCK" }
]
```

پس از جای‌گذاری:

```json
{
  "outbounds": [
    { "protocol": "freedom", "tag": "DIRECT" },
    { "protocol": "blackhole", "tag": "BLOCK" }
  ]
}
```

**آبجکتِ دارای ارجاع به‌طور کامل جایگزین می‌شود.** اگر کنار `snippet` چیز دیگری بنویسید، از دست می‌رود – در مثال زیر `tag` به پیکربندی نهایی نمی‌رسد:

```json
{
  "snippet": "my-outbounds",
  "tag": "این کلید دور انداخته می‌شود"
}
```

اگر اسنیپتی با نام داده‌شده وجود نداشته باشد، عضوِ دارای ارجاع به‌سادگی از آرایه حذف می‌شود.

#### در ریشه

همه‌ی اسنیپت‌های فهرست‌شده در `snippets` در یک مجموعه‌ی واحد از بخش‌ها جمع می‌شوند و به ریشه‌ی پیکربندی افزوده می‌شوند. خود فیلد `snippets` از پیکربندی نهایی حذف می‌شود.

در اینجا سه قاعده برقرار است.

**بخش‌هایی که از پیش در پروفایل نوشته شده‌اند بازنویسی نمی‌شوند.** اگر پروفایل `log` مخصوص خودش را داشته باشد و اسنیپت هم `log` بیاورد – همان که در پروفایل نوشته شده باقی می‌ماند. این کار عمدی است: آنچه با دست خودتان نوشته‌اید مهم‌تر از چیزی است که از یک پیش‌تنظیم آمده.

**بعضی بخش‌ها هرگز جای‌گذاری نمی‌شوند.** این‌ها `inbounds`، `api`، `stats`، `metrics` و `snippets` هستند – مدیریت آن‌ها با Remnawave است و اسنیپت نمی‌تواند آن‌ها را جایگزین کند. اگر اسنیپتی چنین بخش‌هایی داشته باشد، بی‌سروصدا نادیده گرفته می‌شوند و بقیه‌ی بخش‌های آن مثل همیشه اعمال می‌شوند. در ویرایشگر اسنیپت این بخش‌ها در دسترس نیستند و به‌عنوان خطا مشخص می‌شوند.

**ترتیب اهمیت دارد.** اگر دو اسنیپت در فهرست یک بخش یکسان را بیاورند، آنکه دیرتر ذکر شده برنده است.

اگر اسنیپتی با نام داده‌شده وجود نداشته باشد، آن نام به‌سادگی نادیده گرفته می‌شود.

#### ترتیب پردازش

نخست ریشه پردازش می‌شود و سپس آرایه‌ها. به همین دلیل یک اسنیپت ریشه‌ای می‌تواند برای نمونه بخش `outbounds` را بیاورد که داخل آن ارجاع به اسنیپت‌های دیگر وجود دارد – آن‌ها هم باز می‌شوند.

تودرتویی **فقط یک سطح** کار می‌کند: اسنیپتی که از دل اسنیپت دیگری جای‌گذاری شده، دیگر باز نمی‌شود. فیلد `snippets` داخل یک اسنیپت ریشه‌ای نادیده گرفته می‌شود.
